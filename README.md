# Framer Components by @ui.ananya_

A small library of custom web components I made for my reels. They're free to use in Framer, or in any React or Next.js project.

You can also point an AI coding tool like Claude Code at this repo, and it will use these components in the site it builds instead of making something generic.

## Components

### Dangle Necklace
A pendant that drops in on a physics chain. Visitors can grab it, swing it and pull more chain down from the top.
[View component](components/dangle-necklace)

### Metallic Frame
A spiky chrome frame that goes around any image. Click it and the metal starts reflecting you through your camera.
[View component](components/metallic-frame)

### Emboss Footer
A metal plate for the bottom of your site with your name pressed into it. Visitors can draw on it and every line gets embossed.
[View component](components/emboss-footer)

## How to use

**In Framer:** open a component's folder, copy the code from the .tsx file, and paste it into a new code component in Framer. Each folder has a README with setup steps and what every control does.

**With Claude Code:** tell it something like "use the components from github.com/ananyamaid/framer-components in this site". It will read the CLAUDE.md file in this repo and use the components the way they're meant to be used.
